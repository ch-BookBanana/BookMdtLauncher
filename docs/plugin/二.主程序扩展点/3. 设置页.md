# 二.主程序扩展点 | 3.设置页

## core/setting：分组就是子点

设置页的分组是 `core/setting` 点下的**子点**，条目是子点上的设置项：

```python
from BMLCore import register, Widgets

# 分组（子点）：title 是语言键；顺序 = 登记顺序
group = register("core/setting")
group.add("core.setting.mine", type="core/setting",
          title="my.group")

# 条目：build 建控件，default 是初值，attr 是挂到页面上的属性名（可选）
group.get("core.setting.mine").add(
    "probe", default=True, title="my.probe",
    build=lambda ctx: Widgets.control(ctx, Widgets.Bool))
```

内置分组：`core.setting.preferences` / `core.setting.general` /
`core.setting.java` / `core.setting.plugins`（插件默认落在最后一个）。

> ⚠️ **`core/setting` 的 `add` 与普通 Point.add 不同**：`BSettingPoint` 覆写过
> `add` —— 内部先 `super().add(...)`，再写 `default=` 的初值、挂 `build=` 的
> 控件工厂。所以「设置条目 = 加一个控件」，不是「加一条元数据」。
>
> 📌 元数据（标题、说明）**不存条目**，`build(ctx)` 里手动传给控件：
> `ctx.title` 就是条目的 title。

## 条目怎么建控件

`build(ctx)` 拿到一个 Box：`ctx.parent` 是挂载父控件、`ctx.title` 是语言键、
`ctx.entry` 是这条设置项本身。两种写法：

```python
# 1) 值型控件：一行接好「控件 ↔ 条目」
build=lambda ctx: Widgets.control(ctx, Widgets.Bool)     # 或 Combo / Slider

# 2) 自己画：返回什么就摆什么，线自己接
def build(ctx):
    w = MyWidget(ctx.parent)
    w.push.connect(lambda v: ctx.entry.set(v))
    ctx.entry.value_changed.connect(lambda *_: w.show_value(ctx.entry.get()))
    return w
```

条目上的 `attr="…"` 会让控件挂到设置页对象上（给手写接线代码用），
`spacing=30` 是这一项上方的空隙。

## 插件侧：Plugin.add_setting

```python
class MyPlugin(BMLPlugin):
    settings_defaults = {"greet": True}

    def __init__(self, host):
        super().__init__(host)
        # 值型控件：自动和设置键 greet 双向同步（拨动写回、别处改了界面刷新）
        self.add_setting("greet", Widgets.Bool, title="my.greet")

        # 想自己记控件 / 自己接线：给 build
        self.add_setting("greet2", title="my.greet2", build=self._build_greet)
```

默认落在 `plugins` 分组；想进别的组就传 `section="core.setting.java"`（全名或末段都行）。
插件卸载时它的设置项跟着条目一起下台（界面自动少一颗开关）。

## 值存哪

条目就是值本身（`entry.get()` / `entry.set(v)`）；
插件侧用 `add_setting(名字, …)` 时，值落在插件自己的设置桶里
（`self.get_config("greet")` 读到的就是它），默认值写在 `settings_defaults`。
