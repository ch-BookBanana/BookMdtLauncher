# 二.主程序扩展点 | 1.页面

## core/pages：主窗口左栏导航页

```python
from BMLCore import registrar

@registrar("core/pages").new(title="hello.page")
def page(self, ctx):
    return MyPage(ctx.parent)
```

- 构建函数每次调用必须返回**新控件**
- `ctx.parent` 是挂载父对象；`ctx.title` 是语言键
- 顺序 = 登记顺序（谁先登记谁排在前面，没有 order 这种权重）；`icon` 可选
- 卸载时页面热摘：导航按钮与页面一起消失

## 页面接口：两种都行，按需要选

装配方对页面只有两条要求：**左栏按钮能切过去、内容能摆出来**。所以：

```python
# 写法一：普通控件当整页（最简单）
@registrar("core/pages").new(title="hello.page")
def page(self, ctx):
    return QLabel("整页就是这一个控件")
```

这种页面会被塞进主栏栈：点左栏按钮，整页显示，左右两栏保持原样。

```python
# 写法二：自己实现 changePage()，独占三栏
class MyPage(QWidget):
    def __init__(self, ctx):
        super().__init__()
        ...
        self.left = ...    # 左栏控件
        self.main = ...    # 主栏控件
        self.right = ...   # 右栏控件

    def changePage(self):
        shell = register("core/shell/workspace")   # 宿主体：left / main / right
        shell.left.setCurrentWidget(self.left)
        shell.main.setCurrentWidget(self.main)
        shell.right.setCurrentWidget(self.right)
```

有 `changePage()` 就由页面自己负责把三栏切到当前（内置页面继承
`src/utils/pages` 的 `Page`，那个基类已经写好这套逻辑）。装了 `left`/`main`/`right`
却没实现 `changePage()` 的控件，装配方只会把它当普通整页控件用 —— 三栏不会跟着切。

> ⚠️ 只有 `default=True` 的页面才会启动时自动显示；不写就是第一页。
> 页面被卸载时，装配方会把它从三栏/主栏栈里摘掉并 `deleteLater()`，
> 所以页面里起的定时器、线程记得在 `on_close()` 里停。

## core/start/bottom：启动页左栏底部按钮

同上，构建函数返回按钮控件；`default=True` 可指定启动默认页（仅在 `core/pages`）。

## 契约

`init`（构建函数）、`title`、`icon`；其它字段登记会报「未知字段」。
