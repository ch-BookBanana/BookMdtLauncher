# 二.主程序扩展点 | 4.下载页

| 扩展点 | 字段 | 说明 |
|---|---|---|
| `core/download/tabs` | `init` `title` `icon` | 下载页左栏的页签 |
| `core/download/sources` | `init` `title` `icon` | 下载页顶部页签的游戏来源 |
| `core/download/item/actions` | `init` `title` `icon` | 下载列表项右侧的操作按钮 |

```python
@registrar("core/download/sources").new(title="hello.src", icon=…)
def src(self, ctx):
    return MySourceTab(ctx.parent)
```

构建函数返回控件；按钮类条目应返回可点击的按钮控件。
