# 二.主程序扩展点 | 7.托盘与样式

## core/tray/menu：系统托盘右键菜单

```python
@registrar("core/tray/menu").new(title="hello.about")
def about(self, ctx):
    act = QAction(events.lang.get("hello.about"), ctx.parent)
    act.triggered.connect(self._on_about)
    return act
```

- 构建函数返回 `QAction`
- `title` 是语言键，切语言时托盘自动重设文案

## core/qss：全局样式片段

```python
css = registrar("core/qss").new("helloCss", qss="QLabel#x{color:red}", theme=None)
```

- 类属性里挂（标记对象），apply/加载时落地
- `theme`：`None` 两套主题都加、`True` 仅浅色、`False` 仅深色
- 片段排在主题文件之后，同名选择器以插件为准
