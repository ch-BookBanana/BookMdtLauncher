# 二.主程序扩展点 | 7.托盘与样式

## core/tray/menu：系统托盘右键菜单

```python
@registrar("core/tray/menu").add(title="hello.about")
def about(self, ctx):
    act = QAction(events.lang.get("hello.about"), ctx.parent)
    act.triggered.connect(self._on_about)
    return act
```

- 构建函数返回 `QAction`
- `title` 是语言键，切语言时托盘自动重设文案

## core/qss：全局样式片段

```python
css = registrar("core/qss").add("helloCss", qss="QLabel#x{color:red}", theme=None)
```

- 类属性里挂（标记对象），apply/加载时落地
- `theme`：`None` 两套主题都加、`True` 仅浅色、`False` 仅深色
- 片段排在主题文件之后，同名选择器以插件为准

## 取色：core/theme

自绘控件（`QPainter`、`change_color` 涂图标）**别写死颜色，也别去读 qss 文件** ——
用主题服务：

```python
theme = register("core/theme")
color = QColor(theme.get("panel"))        # 当前主题
icon = change_color(getPath("..."), QColor(theme.get("brand")))
```

角色名与明暗取值见[一.插件基础 · 内置服务](../一.插件基础/7.%20内置服务.md)；
`theme.changed` 在切主题后发出，自绘的东西重画一次即可。

> 📌 `core/qss` 管的是规则（选择器、边框、间距），`core/theme` 管的是
> 需要喂给 `QColor` 的纯色 —— 两者别互相替代。

> 📌 自绘的小控件想套现成外观，可以设 `wid` 为内置角色（`btn` / `btn-text` /
> `text` / `panel-alt` …）；完整清单见 `src/resources/styles/*.qss`。`wid_` 是宿主
> 给自己 `setStyleSheet` 用的作用域属性（只命中本控件、不传给子控件），插件别用。
