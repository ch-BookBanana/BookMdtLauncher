# 二.主程序扩展点 | 2.浮层

| 扩展点 | 目录 | 行为 |
|---|---|---|
| `core/overlays` | `pages/Modal/` | 盖在窗口上、带遮罩、内容居中（Modal） |
| `core/stacks` | `pages/Stack/` | 整页浮层栈，一页压一页、可逐级返回 |

```python
@registrar("core/overlays").new(title="hello.overlay")
def overlay(self, ctx):
    return MyOverlay(ctx.parent)
```

- 登记后需要打开时：`events.emit("overlayRequested", widget)` / `stackRequested`
- 关闭：`events.emit("overlayClosed", self, True)`
- 覆盖宿主内置（如关闭询问 `core.closeAsk`）用 `self.override(...)`（旧 registrar 语法，v3 迁移中）
