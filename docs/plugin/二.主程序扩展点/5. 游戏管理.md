# 二.主程序扩展点 | 5.游戏管理

| 扩展点 | 字段 | 说明 |
|---|---|---|
| `core/gameManager/pages` | `init` `title` `icon` | 游戏管理浮层左栏的功能页 |
| `core/gameSettings/sections` | `init` `spacing` | 游戏管理页的区块（文件夹 / Java …） |

```python
@registrar("core/gameManager/pages").new(title="hello.mods")
def mods(self, ctx):
    return ModsPanel(ctx.parent)
```

功能页拿到的是「当前游戏实例」；区块会按 `spacing` 排列。
