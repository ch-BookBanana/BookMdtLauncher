# 插件能用哪些包

插件运行在启动器进程内，可导入的模块集合由启动器打包时包含的内容决定。本文列出当前可用的
模块；不在列表中的模块需要由插件自带（见第四节）。缺少依赖时导入会抛出
`ModuleNotFoundError`，该插件会被记录为加载失败。

## 一、Qt（PySide6）

| 模块 | 内容 |
|------|------|
| `PySide6.QtCore` | 信号槽、QObject、QTimer、QSize / QPoint 等基础类型 |
| `PySide6.QtGui` | QIcon / QColor / QPixmap / QFont / QPainter |
| `PySide6.QtWidgets` | 控件、布局、对话框（QWidget / QLabel / QPushButton / QVBoxLayout 等） |
| `PySide6.QtNetwork` | QNetworkAccessManager 等网络类 |

当前包含以上四个模块。`QtMultimedia`、`QtWebEngine` 等其余模块未包含在内；这些模块是编译好的
二进制，需由启动器侧补充，插件自身无法添加。

## 二、第三方包

| 包 | 说明 |
|----|------|
| `requests` | 启动器的下载流程使用 |
| `urllib3` | `requests` 的依赖 |
| `certifi` | CA 证书 |
| `markdown` | Markdown 渲染 |
| `shiboken6` | PySide6 的绑定层，通常无需直接导入 |

未列出的第三方包（如 `Pillow`、`numpy`）需由插件自带，见第四节。

## 三、标准库

内置库大部分可用，例如：

`json` / `os` / `re` / `threading` / `queue` / `time` / `datetime` / `subprocess` /
`urllib` / `sqlite3` / `zipfile` / `hashlib` / `ctypes` / `pathlib`

与启动器功能无关的模块（`tkinter`、`idlelib`、`turtle`、`curses` 等）不包含在内。

## 四、插件自带依赖

纯 Python 依赖放在插件目录的 `libs/` 下：

```text
BML/plugins/hello/
├── manifest.toml
├── main.py
└── libs/
    └── tinytag/               # 此后 import tinytag 可用
        ├── __init__.py
        └── ...
```

加载该插件时，宿主会把 `<插件目录>` 与 `<插件目录>/libs` 加入 `sys.path`，卸载时移除。
同目录模块与 `libs/` 下的依赖均可直接导入，无需修改 `sys.path`。

含有 C 扩展的包（numpy、Pillow、lxml 等，包含 `.pyd`）需要与启动器所用 CPython 版本及 ABI
一致，使用前需先验证；不可用时改用纯 Python 实现。
