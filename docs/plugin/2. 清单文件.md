# 清单文件

清单使用 `manifest.toml`；旧的 `plugin.json` 仍然支持。

```toml
id = "you_hello"                # 必填：标识符，建议带上作者名（见下）
name = "Hello"                  # 显示名，缺省与 id 相同
version = "1.0.0"
api = "1.x"
main = "main.py"                # 入口文件名
entry_class = "Hello"           # 入口类名，缺省时自动发现
author = "you"
description = "示例插件"
dependencies = ["you_base"]     # 依赖的插件 id 列表（数组）
```

## 字段

| 字段 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `id` | 是 | — | 标识符；同时用作注册表命名空间、事件前缀、设置格子名与包名 |
| `name` | 否 | 同 `id` | 显示名 |
| `version` | 否 | `0.0.0` | 插件版本 |
| `api` | 否 | `1.x` | 兼容的宿主 API 范围 |
| `main` | 否 | `main.py` | 入口文件（旧名 `entry` 同样识别） |
| `entry_class` | 否 | 自动发现 | 入口类名；未提供时取本文件中最派生的 `Plugin` 子类 |
| `author` / `description` | 否 | 空 | 说明性字段 |
| `dependencies` | 否 | 空 | 依赖的插件 id 列表（数组；只依赖一个时写字符串也认） |

## id 的写法

`id` 只能用字母、数字与下划线，且首字符是字母；不能是 `core`、`src`、`main`、
`bmlcore`、`bmlplugin`、`bml_plugin` 这些保留名。它同时是注册表命名空间、事件名前缀、
设置里的格子名，以及插件代码的包名，所以**不接受点号与短横线**。

建议把作者名融进 id，避免与别人的插件重名：

```toml
id = "bookbanana_more_widgets"     # 作者_插件
id = "ncatbot_plugin_market"       # 也可再加一层用途
```

同一个 id 不允许装两次：发现重复时两个插件都会被标为加载失败，日志里写明是哪两份。

`id` 定了就别改：注册表条目 key、事件名、设置里那一格（`pluginSettings`）都按它算，
改名等于换了一个插件。

## api 版本号

宿主当前 `API_VERSION = 1.0`：

| 写法 | 含义 | 是否接受 |
|------|------|---------|
| `1.x` | 同一大版本（推荐） | 是 |
| `1.0` / `1` | 精确版本 / 仅限大版本 | 是 |
| `>=1.0,<2.0` | 区间 | 是 |
| `1.1` / `2.x` | 要求更高的版本 | 否 |

## 报错信息

| 情况 | 日志内容 |
|------|---------|
| 两种清单均不存在 | `缺少 manifest.toml（或旧的 plugin.json）` |
| 解析失败或顶层不是对象 | `manifest.toml 读不了或不是合法清单：…` |
| `id` 缺失 / 不含 `.` / 使用 `core` | 各自对应的说明 |
| `dependencies` 含非字符串项 | `dependencies 里只能是字符串` |
| `entry_class` 不是 `Plugin` 子类 | `里找不到 entry_class = 'X'` |
