## 最小插件（30 行以内）

```
BML/plugins/hello/
├── data.hjson
└── main.py
```

```hjson
// data.hjson
{
  id: example_hello
  name: Hello
  version: 1.0.0
  api: 2.x
  entry: main.Hello
}
```

```python
# main.py
from BMLCore import BMLPlugin, register


class Hello(BMLPlugin):
    id = "example_hello"

    def __init__(self, host):
        super().__init__(host)
        me = register()                                # 自己的点
        parts = me.add("parts", type="core/point", entry="core/value")
        parts.add("greeting").set("你好")

    def on_ready(self):
        register("core/log").info("Hello 已加载")       # 内置服务
```

复制到 `BML/plugins/` 下、启动启动器即可加载。

## 推荐阅读路径

- **只想加一个页面/设置项/托盘项** → 先看[扩展点](二.主程序扩展点/README.md)对应那篇，再看[注册语法](一.插件基础/3.%20注册语法.md)
- **想写完整插件（依赖、设置、信号、资源）** → 从[目录与清单](一.插件基础/1.%20目录与清单.md)按顺序读
- **调试加载失败** → [加载失败与停用](一.插件基础/8.%20加载失败与停用.md)

## 当前状态

- 插件 API 正在从 v2 迁到 v3（万物皆 BType + 点体系）
- 新写的插件请用 v3 写法（`register()` / `add()` / `generator(...)`）
- v2 旧写法（`@registrar(...).new(...)`）仍能跑，属过渡期，文档里会标明
