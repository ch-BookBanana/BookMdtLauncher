# 生命周期

```text
扫描 BML/plugins
 └─ 读取清单（清单不合法时立即报错）
     └─ 按 dependencies 先加载依赖（缺依赖或成环则本次加载失败）
         └─ 导入入口文件 → 选定插件类（entry_class 或最派生子类）
             └─ cls(host)        构造：初始化与登记
                 └─ registrar.apply()   装饰器登记落地
                     └─ 全部插件加载完成 → on_ready() → 界面构建
卸载（停用 / 重载 / 退出）
 └─ 摘除注册项 → 摘除事件 → 摘除插件创建的控件 → on_close()
```

## 示例

```python
class Hello(BMLPlugin):
    id = "example_hello"

    def __init__(self, host):
        super().__init__(host)
        self.cache = {}                       # 插件自身的初始化

    @registrar.setting(title="hello.greet")
    def build_greet(self, ctx):
        return Widgets.Bool(ctx.parent, ctx.title)

    @registrar.on_ready()
    def ready(self):
        self.log("所有插件加载完成")

    def on_close(self):
        self.log("清理完成")
```

## 约定

- 登记为全有或全无：`__init__` 中途抛出异常时，本次登记的条目整体回滚，重试不会触发「已存在条目」。
- 单个插件失败不影响其它插件，也不影响启动器启动。
- `__init__` 中不应创建控件或阻塞（界面尚未构建）；耗时操作应放入线程或 `on_ready()`。
