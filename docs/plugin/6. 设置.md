# 设置

插件设置存放在宿主 `settings.json` 的 `pluginSettings` 下，每个插件占一个格子：

```json
{ "pluginSettings": { "example_hello": { "volume": 30, "greet": false } } }
```

## 完整示例

```python
from BMLCore import BMLPlugin, Widgets, registrar


class Hello(BMLPlugin):
    id = "example_hello"
    # 默认值集中声明：读取未存过的键时回落到此
    settings_defaults = {"greet": True, "volume": 50, "runs": 0}

    def __init__(self, host):
        super().__init__(host)

        # 读取：已存过则返回存值，否则返回默认值
        self.volume = self.get_config("volume")          # 50
        self.log("音量 %s" % self.volume)

        # 监听键值变化：经 set_config 修改时触发（直接写 self.settings 不触发）
        self.watch_config("volume", self._apply_volume)

        # 计数累加，用于确认写入已持久化
        self.set_config("runs", self.get_config("runs") + 1)

    @registrar.setting(title="hello.greet")               # 设置页中的一项
    def build_greet(self, ctx):
        w = Widgets.Bool(ctx.parent, ctx.title)               # Bool / Combo / Slider 均可
        w.btn.setChecked(self.get_config("greet"))            # 初值取当前设置
        w.push.connect(lambda v: self.set_config("greet", v)) # 勾选变化写回设置
        return w

    def _apply_volume(self, value):
        self.volume = value
        self.log("音量改为 %s" % value)                    # 相关重算在此进行

    def reset(self):
        # 删除已存值，此后读取回落到默认值
        del self.settings["volume"]
```

| 写法 | 触发 `watch_config` | 写盘 |
|------|--------------------|------|
| `self.set_config(k, v)` | 是 | 立即 |
| `self.settings[k] = v` | 否 | 立即 |
| `self.settings["opts"]["rank"] = 2` | 否 | 宿主防抖（约 500ms） |
| `self.settings.save()` | 否 | 立即 |

## 嵌套结构

`self.settings["opts"]` 是该格子内的子对象，`self.settings["opts"]["rank"] = 2`
这类就地修改会通知宿主（宿主自己防抖落盘），但不会触发 `watch_config` 的回调 ——
后者只由 `set_config` 驱动。需要立刻写盘时显式调用：

```python
self.settings["opts"]["rank"] = 2      # 就地修改
self.settings.save()                   # 需要立即写盘时调用
self.settings["opts"] = {"rank": 2}    # 或整键重写（写键会自动写盘）
```

## 私有数据与目录

```python
class Hello(BMLPlugin):
    id = "example_hello"

    def on_ready(self):
        # data 为 dict，持久化到 BML/pluginData/<id>/data.json
        self.data["runs"] = self.data.get("runs", 0) + 1
        self.save_data()                            # 修改后需保存

        self.log("私有目录：%s" % self.workspace)     # 不存在时自动创建
```

- 设置与 `pluginData` 在插件卸载后保留，停用再启用时配置不变。
- `self.settings` 为视图，不包含 `language` / `theme` 等宿主配置项。
