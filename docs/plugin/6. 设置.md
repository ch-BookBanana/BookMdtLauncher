# 设置

v2 的 `settings.json` **顶层分桶**：宿主自己的配置在 `core` 桶里，每个插件各占一格，键就是插件 id。

```json
{
  "core": { "language": "zh-CN", "theme": 0, "java": "" },
  "example_hello": { "volume": 30, "greet": false }
}
```

- 宿主代码仍按老写法 `settings["language"]` 平铺读写（内部转发到 `core` 桶），插件不用管。
- 旧文件（宿主键平铺 + `pluginSettings` 结构）读入时**自动迁移**：下次存盘就是上面的 v2 形状。
- 插件侧只走 `self.settings`（视图），不直接摸 `settings.json`。

## 完整示例

```python
from PySide6.QtWidgets import QLabel, QVBoxLayout, QWidget

from BMLCore import BMLPlugin, Widgets, registrar


class Hello(BMLPlugin):
    id = "example_hello"
    # 默认值集中声明：这些键在视图构造时就自动声明过了
    settings_defaults = {"greet": True, "volume": 50, "runs": 0}

    def __init__(self, host=None):
        super().__init__(host)

        # 读：已存过则返回存值，否则返回默认值
        self.volume = self.get_config("volume")            # 50
        self.log("音量 %s" % self.volume)

        # 盯键值变化：只由 set_config 驱动
        self.watch_config("volume", self._apply_volume)

        # 写：set_config 写值 + 通知回调
        self.set_config("runs", self.get_config("runs") + 1)

        # 运行期补声明的新键（之后才能写）
        self.settings.declare("last_dir", "")
        self.set_config("last_dir", self.workspace)

    @registrar("core/setting/items").new(title="hello.greet",
                                         section="core.setting.plugins", order=910)
    def build_greet(self, ctx):
        w = Widgets.Bool(ctx.parent, ctx.title)             # Bool / Combo / Slider 均可
        w.btn.setChecked(self.get_config("greet"))          # 初值取当前设置
        w.push.connect(lambda v: self.set_config("greet", v))   # 勾选变化写回设置
        return w

    def _apply_volume(self, value):
        self.volume = value
        self.log("音量改为 %s" % value)                     # 相关重算在此进行
```

## 视图的规矩

| 操作 | 行为 |
|------|------|
| `self.settings["volume"]` | 读：没存过就回默认值；**没声明过**的键抛 `KeyError` |
| `self.settings["volume"] = 30` | 写：未声明的键**直接报错**（防拼错键名），写值顺手存盘 |
| `self.settings.declare("k", 默认)` | 运行期补声明（值只是默认值，不会立刻写进格子） |
| `self.get_config("k", 默认)` | 读：先看存值 → 再退 `settings_defaults` → 再退给的默认值 |
| `self.settings.other("core")["theme"]` | 跨桶读：路径摆明面上，桶名拼错不会被兜成空 dict |
| `self.register("core/settings").get("theme")` | 同一个跨桶读的另一种写法（显式命名空间） |
| `del self.settings["k"]` | 删键，此后读取回落到默认值 |
| `self.settings.as_dict()` | 默认值 + 已存值合并后的普通 dict（调试、写日志用） |

## 变更通知与存盘

| 写法 | 触发 `watch_config` | 存盘 |
|------|--------------------|------|
| `self.set_config("k", v)` | 是 | 是 |
| `self.register("settings").set("k", v)` | 是 | 是 |
| `self.settings["k"] = v` | 否 | 是（宿主自个儿防抖落盘） |
| `self.settings.declare("k", v)` | 否 | 否（只登记默认值） |

`watch_config` 的回调收到新值；回调里抛异常只记日志，不会打断派发。

## 跨桶读宿主配置

插件看宿主配置要走显式路径，别指望它混进自己的键空间：

```python
def on_ready(self):
    light = self.settings.other("core")["theme"]        # True 为浅色
    lang = self.register("core/settings").get("language")
    self.log("浅色=%s 语言=%s" % (light, lang))
```

`core/settings` 对插件只读：写别人的桶会被拒（`不能给 'core' 的桶声明设置键` / `别的桶不给写`）。

## 保留与持久化

- 设置与 `pluginData/` 在插件卸载后保留，停用再启用时配置不变。
- 卸载时插件的整格设置**不会**被删；只有明确「彻底不要这个插件」时才摘。
- 累计状态放 `self.settings`（例如 `runs`），不要指望 v1 的 `self.data` —— v2 没有它。
