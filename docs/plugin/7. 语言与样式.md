# 语言与样式

## 语言包

位于 `<插件>/langs/<语言>.json`，文件名即语言代码（`zh-CN` / `zh-TW` / `en-US` / `ja-JP` /
`ko-KR` / `lzh`）：

```json
{
  "hello.page.head": "问候一下",
  "hello.greet": "打个招呼",
  "core.wid.pages.start.startbtn": "开始游戏！"
}
```

- 键由插件自己定义（推荐带插件前缀，如 `hello.page`），也可以覆盖内置键；内置键统一带 `core.`
  前缀，文件位于 `src/lang/<语言>.json`。
- 插件语言包在装载器加载之后合并进宿主 Langer，按加载顺序后者覆盖前者；**卸载后自动回内置文案**
  （插件覆盖过的内置键会回到宿主那一份）。
- 登记时的 `title=` 即语言键，内置控件在切换语言时会自动重新取值。

自绘控件读取文案：

```python
from PySide6.QtWidgets import QLabel, QVBoxLayout, QWidget

from BMLCore import events


class GreetPanel(QWidget):
    """文案在构造时读取一次，切换语言时不会自动重取（见「已知限制」）。"""

    def __init__(self, parent=None):
        super().__init__()
        lay = QVBoxLayout(self)

        title = QLabel(events.lang.get("hello.page.head"))   # 语言键 → 当前语言文案
        title.setObjectName("helloHead")                     # 供样式选择器使用
        title.setProperty("wid", "text")                     # 沿用内置字体与配色规则
        lay.addWidget(title)
```

`self.lang` 就是宿主翻译器（与 `events.lang` 同一个对象）：

```python
def on_ready(self):
    label = self.lang.get("hello.greet")      # 取不到时 Langer 内部按内置规则回退
    self.log("当前文案：%s" % label)
```

## 样式

用 `core/qss` 命名空间登记片段；构建期不需要控件，所以常写成类属性标记：

```python
class Hello(BMLPlugin):
    id = "example_hello"

    # 两套主题都生效
    common = registrar("core/qss").new("hello.css", qss="QLabel#helloHead { font-weight: bold; }")

    # theme=True → 只在浅色
    light = registrar("core/qss").new("hello.light", qss="QLabel#helloHead { color: #223344; }",
                                      theme=True)

    # theme=False → 只在深色
    dark = registrar("core/qss").new("hello.dark", qss="QLabel#helloHead { color: #dde3ee; }",
                                     theme=False)
```

| `theme` | 含义 |
|---------|------|
| `None` | 两套主题均生效（默认） |
| `True` | 仅浅色主题 |
| `False` | 仅深色主题 |

- 片段排在主题文件之后，同名选择器以它为准 —— 能盖内置样式，不必改主题文件。
- 换主题时宿主会重新收一遍片段，插件不用自己监听。
- 运行期也可以登记：`self.register("core/qss").new("hello.extra", qss="…", theme=None)`。
