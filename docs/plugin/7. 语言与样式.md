# 语言与样式

## 语言包

位于 `<插件>/langs/<语言>.json`：

```json
{
  "hello.page.head": "问候一下",
  "hello.greet": "打个招呼",
  "core.wid.pages.start.startbtn": "开始游戏！"
}
```

- 键可以是新增的，也可以是内置键；插件覆盖内置，后加载的插件覆盖先加载的。
- 内置键统一带 `core.` 前缀，文件位于 `src/lang/<语言>.json`（当前 6 种语言）。
- 装饰器的 `title=` 即语言键，内置控件在切换语言时会自动重新取值。

自绘控件读取文案的方式：

```python
from PySide6.QtWidgets import QLabel, QVBoxLayout, QWidget

from BMLCore import events


class GreetPanel(QWidget):
    """文案在构造时读取，切换语言时不会重新取值（参见「已知限制」）。"""

    def __init__(self, parent=None):
        super().__init__()
        lay = QVBoxLayout(self)

        title = QLabel(events.lang.get("hello.page.head"))   # 语言键 → 当前语言文案
        title.setObjectName("helloTitle")                    # 供下方 qss 选择器使用
        title.setProperty("wid", "text")                     # 沿用内置字体与配色规则
        lay.addWidget(title)
```

## 样式

通过类属性声明（推荐，可一次提交多个片段）：

```python
class Hello(BMLPlugin):
    id = "example_hello"

    # theme=True → 仅在浅色主题生效
    light = registrar.qss("""
QLabel#helloTitle {
    color: #223344;
}""", theme=True)

    # theme=False → 仅在深色主题生效
    dark = registrar.qss("""
QLabel#helloTitle {
    color: #dde3ee;
}""", theme=False)

    # 未指定 theme → 两套主题均生效
    common = registrar.qss("""
QLabel#helloTitle {
    font-weight: bold;
    padding: 4px 0;
}""")
```

运行时追加片段：

```python
def on_ready(self):
    # 片段排在主题文件之后，同名选择器以该片段为准
    self.add_qss("QPushButton#helloBtn { border-radius: 6px; }", theme=None)
```

| `theme` | 含义 |
|---------|------|
| `None` | 两套主题均生效（默认） |
| `True` | 仅浅色主题 |
| `False` | 仅深色主题 |

切换主题时宿主会重新收集片段，插件无需监听。
