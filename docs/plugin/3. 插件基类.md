# 插件基类

基类分两级：`Plugin` 为最小实现，`BMLPlugin` 在其基础上提供设置、私有数据与私有目录。

```python
from BMLCore import BMLPlugin, Plugin, registrar


class Minimal(Plugin):
    """仅登记条目时使用：host 同样提供 log / lang / registry。"""

    id = "example_minimal"

    def __init__(self, host):
        super().__init__(host)
        host.log("minimal 已加载")


class Full(BMLPlugin):
    """需要设置、私有数据或私有目录时使用。"""

    id = "example_full"
    settings_defaults = {"greet": True}     # 设置默认值
```

## 初始化

初始化代码写在 `__init__` 中：

```python
class Hello(BMLPlugin):
    id = "example_hello"
    settings_defaults = {"volume": 50}

    def __init__(self, host):
        super().__init__(host)              # 首句：保存 host
        self.closed = False

        host.log("开始加载")                 # 输出至 BML/logs

        # 初始化：读取设置、建立缓存、启动线程等
        self.volume = self.get_config("volume")
        self.cache = {}
        icon = self.path("assets/icon.png")  # 插件目录内文件的绝对路径
        host.log("图标位于 %s" % icon)

        # 事件订阅可直接在此进行；装饰器登记在构造完成后落地
        host.events.on("start_gameChanged", self._on_game)

    def _on_game(self, data):
        self.log("宿主切换游戏：%s" % (data,))

    def on_close(self):
        self.closed = True                  # 停止线程、关闭文件、删除临时目录
```

## host 句柄

`host` 是一个接口固定的小对象，全部工具集中于此：

| host 成员 | 说明 | 等价写法 |
|-----------|------|---------|
| `host.log(msg, level=…)` | 带 `[id]` 前缀的日志 | `self.log(…)` |
| `host.lang` | 翻译服务，`host.lang.get("<键>")` | `self.lang` |
| `host.settings` | 本插件设置视图 | `self.settings` |
| `host.events` | 事件总线 | `self.on` / `self.emit` |
| `host.registry` | 注册表 | — |
| `host.path(rel)` | 插件目录内文件的绝对路径 | `self.path(rel)` |
| `host.workspace()` | 私有目录，不存在时创建 | `self.workspace` |
| `host.id` / `host.plugin_dir` / `host.data_dir` | 标识与目录 | — |

## 登记动作

| 方法 | 说明 |
|------|------|
| `self.add(point, name, **fields)` | 登记一条自己的条目，key 自动加 `<id>.` 前缀 |
| `self.override(point, key, **fields)` | 顶掉别家已有的一条（内置条目也可），卸载时自动回退 |
| `self.publish(name, obj)` | 把类 / 工厂 / 服务发布出去，别的插件按 `<id>.<name>` 取 |
| `self.use(key)` | 取别的插件发布的东西（返回活句柄，见[资源与依赖](9.%20资源与依赖.md)） |
| `self.add_setting(name, cls, title=…)` | 往设置页加一项（不写装饰器时用） |
| `self.add_qss(css, theme=…)` | 追加全局样式片段 |
| `self.add_tray(name, title=…, callback=…)` | 往托盘右键菜单加一项 |
| `self.on(event, callback)` / `self.emit(event, …)` | 订阅 / 广播事件 |

## 类属性

| 属性 | 默认值 | 说明 |
|------|--------|------|
| `id` | `""` | 与清单一致；冲突时以清单为准 |
| `name` / `version` / `api` | `""` / `"0.0.0"` / `"1.x"` | 元信息 |
| `settings_defaults` | `{}` | 设置默认值（`BMLPlugin`） |

## 生命周期方法

| 方法 | 时机 |
|------|------|
| `__init__(host)` | 构造阶段，初始化与登记 |
| `on_ready()` | 所有插件加载完成，界面尚未构建 |
| `on_close()` | 卸载阶段，停止线程与关闭文件 |

## 构建函数的 Ctx 参数

| 字段 | 说明 |
|------|------|
| `ctx.parent` | 挂载点，用作 Qt parent |
| `ctx.title` | 登记时给出的语言键 |
| `ctx.items` | 仅 `@registrar.section` 提供：该分组容纳的条目 |
| `ctx.entry` | 注册表条目，需要读取其它字段时使用 |

```python
@registrar.setting(title="hello.greet")
def build_greet(self, ctx):
    # 使用 ctx.title 而非重复书写键名，确保文案来源唯一
    return Widgets.Bool(ctx.parent, ctx.title)
```
