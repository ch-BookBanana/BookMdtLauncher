# 插件基类

基类分两级：`Plugin` 为最小实现，`BMLPlugin` 在其基础上提供设置、私有目录与配置助手。

```python
from BMLCore import BMLPlugin, Plugin, registrar


class Minimal(Plugin):
    """只登记条目时用：host 同样提供 log / lang / path / events。"""

    id = "example_minimal"

    def __init__(self, host=None):
        super().__init__(host)
        self.log("minimal 已加载")


class Full(BMLPlugin):
    """需要设置或私有目录时用。"""

    id = "example_full"
    settings_defaults = {"greet": True}
```

## 构造与生命周期方法

```python
class Hello(BMLPlugin):
    id = "example_hello"
    settings_defaults = {"volume": 50}

    def __init__(self, host=None):
        super().__init__(host)                  # 首句：保存 host
        self.log("开始加载")                     # 日志带 [example_hello] 前缀
        self.volume = self.get_config("volume")  # 读设置，未存过时回落默认值
        self.icon = self.path("assets/icon.png") # 插件目录内文件的绝对路径

    def on_ready(self):
        # 所有插件都加载完、界面尚未构建
        self.log("就绪")

    def on_close(self):
        # 卸载阶段：停线程、关文件、把要留下的数据写进设置
        self.log("清理完成")
```

| 方法 | 时机 |
|------|------|
| `__init__(host=None)` | 构造阶段：初始化与登记（登记也可以写在装饰器上） |
| `on_ready()` | 所有插件加载完成，界面尚未构建 |
| `on_close()` | 卸载阶段；加载失败回滚时也会调一次，要容忍残缺状态 |

## 类属性

| 属性 | 默认值 | 说明 |
|------|--------|------|
| `id` | `""` | 与清单一致；冲突时以清单为准 |
| `name` / `version` / `api` | `""` / `"0.0.0"` / `""` | 元信息 |
| `settings_defaults` | `{}` | 设置默认值（`BMLPlugin`） |

## 注册动作

v2 只有一个注册出口：`self.register(path)` 返回一个作用域对象，九个动词都从它走
（详见[扩展点](<5. 扩展点.md>)）。

| 方法 | 说明 |
|------|------|
| `self.register(path)` | 运行期注册作用域：`self.register("settings").set("volume", 30)` |
| `self.add(point, name, **fields)` | 登记一条自己的条目；key 自动加 `<id>/` 前缀，卸载时整片摘掉 |
| `self.override(point, key, **fields)` | 顶掉别人/内置的一条；卸载或回滚时自动还回 |
| `self.publish(name, obj)` | 把类 / 工厂 / 服务发布出去，别人按 `<id>.<name>` 取 |
| `self.use(key)` | 取别人发布的东西；返回**活句柄**（随提供方重载现取） |
| `register("core/signals&名").connect(cb)` | 订宿主信号（写全名，不加前缀） |
| `register("signals#名").emit(...)` | 发自己的信号（名字自动加 `<id>.` 前缀） |
| `register("signals#名")` | 自己的信号命名空间（全局总线 `events` 之上的一层） |

## 工具属性

| 成员 | 说明 |
|------|------|
| `self.logger` | 宿主日志器（`debug` / `info` / `warning` / `error`） |
| `self.lang` | 宿主翻译器，`self.lang.get("<键>")` |
| `self.log(msg, level="info")` | 带 `[id]` 前缀的日志 |
| `self.path(rel="")` | 插件目录内文件的绝对路径（加载期外仍可用） |
| `self.id` / `self.host` | 标识符 / 显式句柄 |

## 设置与私有目录（BMLPlugin）

| 成员 | 说明 |
|------|--------|
| `self.settings` | 自己那一格设置的视图（只有声明过的键能写） |
| `self.get_config(key, default=None)` | 读设置：没存过时看 `settings_defaults`，再退到 `default` |
| `self.set_config(key, value)` | 写设置**并**通知 `watch_config` 的回调 |
| `self.watch_config(key, callback)` | 盯一个设置键（只由 `set_config` / `register("settings").set` 驱动） |
| `self.workspace` | `BML/pluginData/<id>/`，不存在时自动创建 |

## 能力句柄：宿主替你收尾

这些资源都由宿主记在自己名下，卸载时自动收拾 —— 写在 `on_close()` 之外作为双保险。

| 方法 | 说明 |
|------|------|
| `self.every(interval_ms, callback)` | 周期回调；卸载时自动停 |
| `self.task(interval_ms, job, events=None, result_callback=None)` | 后台任务：`job(event)` 在共享子线程里跑，返回值交给主线程的 `result_callback` |
| `self.download(url=None, dest_path=None, **kw)` | 用宿主同一套 `QDownloader` 发起下载（默认参数与宿主一致、出现在宿主下载列表） |
| `self.thread(job, name="")` | 一次性后台线程；卸载时 join（最多 5 秒） |
| `self.cleanup()` | 宿主在 `on_close()` 之后调用：计时器停、下载取消并等待、线程 join |

```python
import time


class Hello(BMLPlugin):
    id = "example_hello"

    def __init__(self, host=None):
        super().__init__(host)
        self.tick = 0
        self.every(1000, self._tick)          # 每秒一次
        self.task(0, self._heavy, result_callback=self._loaded)

    def _tick(self):
        self.tick += 1

    def _heavy(self, event):
        time.sleep(0.2)                       # 在共享子线程里跑
        return "算完了"                        # 返回值交给 _loaded

    def _loaded(self, result):
        self.log("后台任务回来了：%s" % (result,))
```

- `self.every(...)` 的返回值是计时器对象，可用 `stop()` / `setInterval(ms)` 控制。
- `self.task(...)` 的 `events` 收一个回调或回调列表：`job` 里用 `event.lambdas[i].emit(值)`
  把中间结果发回主线程。
- `self.task(...)` 返回的是 `QThTimer`：`setInterval` / `stop` / `cancel` / `destroy` 都在它上面；
  长任务要在 `job` 里轮询 `timer.cancel_event.is_set()`（`threading.Event`）才能及时收手，
  所以把返回值存进 `self.xxx`，`job` 里通过 `self.xxx` 取。
- `self.thread(job, name="")` 适合一次性阻塞活；长任务更推荐上面那套（有明确的取消信号）。
- `self.download(...)` 的 `dest_path` 之外，`state_dir` 可指定断点续传状态放哪；
  卸载时宿主自动 `cancel` 并最多等 5 秒。
- `self.cleanup()` 由宿主调，**插件作者不用自己调** —— 正常只写 `on_close()` 就够。

## host 句柄

`host` 是一个接口固定的小对象，工具都在它上面；`self` 上的同名助手只是转发：

| host 成员 | 说明 | 等价写法 |
|-----------|------|---------|
| `host.log(msg, level=…)` | 带 `[id]` 前缀的日志 | `self.log(…)` |
| `host.lang` | 翻译服务 | `self.lang` |
| `host.events` | 事件总线 | `register("core/signals&名")` / `register("signals#名")` |
| `host.registry` | 注册表 | 一般用 `self.register(...)` |
| `host.path(rel)` | 插件目录内文件的绝对路径 | `self.path(rel)` |
| `host.workspace()` | 私有目录，不存在时创建 | `self.workspace` |
| `host.id` / `host.plugin_dir` / `host.data_dir` | 标识与目录 | — |

## 构建函数的 Ctx

| 字段 | 说明 |
|------|------|
| `ctx.parent` | 挂载点，用作 Qt parent |
| `ctx.title` | 登记时给出的语言键 |
| `ctx.items` | 仅分组类条目提供：该组容纳的条目 |
| `ctx.entry` | 注册表条目，需要读取其它字段时使用 |

```python
@registrar("core/setting/items").new(title="hello.greet", section="core/setting/plugins")
def build_greet(self, ctx):
    # 使用 ctx.title 而非重复书写键名，确保文案来源唯一
    return Widgets.Bool(ctx.parent, ctx.title)
```

## 门面导出

`API_VERSION`（当前 `"2.0.0"`）/ `Plugin` / `BMLPlugin` / `Ctx` / `Service` / `registrar` /
`register` / `Widgets` / `events` / `registry` / `simple` / `getPath` / `Signal`。

`registrar` 既当模块（`registrar.apply` / `registrar.collect`）又当工厂：`registrar("命名空间")`
返回作用域；`register` 是同一个工厂，写哪个都一样。

## v2 已经移除的东西

| 已移除 | 替代做法 |
|--------|---------|
| `self.data` / `self.save_data()` | 累计状态放 `self.settings`（声明过的键），文件放 `self.workspace` |
| 自定义 `Signals` 类 / Notifier 模式 | 全局信号总线：`register("signals#名")` 的 `new` / `emit` / `connect` |
| `registrar.page` / `registrar.setting` / `registrar.tray` / `registrar.qss` / `registrar.on` / `registrar.on_ready` | 一律写 `registrar("命名空间").new(...)` |
| `manifest.toml` / `plugin.json` | `data.hjson`（或 `data.json` / `data.toml`） |
