# 验证清单

## 清单文件

- [ ] `manifest.toml`（或旧 `plugin.json`）存在，`id` 含 `.` 且不以 `core` 开头
- [ ] `main` 指向的文件存在；提供 `entry_class` 时该名称对应一个 `Plugin` 子类
- [ ] `api` 与宿主兼容（`1.x` / `1.0` / `1` / `>=1.0,<2.0`）
- [ ] `[dependencies]` 中均为字符串，且不包含自身

## 入口文件

- [ ] 插件类继承 `Plugin` 或 `BMLPlugin`，类属性 `id` 与清单一致
- [ ] 导入范围仅限 `from BMLCore import …`，未导入 `src.*` 或 `main`
- [ ] 初始化写在 `__init__(self, host)` 中，首句为 `super().__init__(host)`
- [ ] `__init__` 中未创建控件、未阻塞
- [ ] 装饰器标注的方法返回控件（`tray` / `on` / `on_ready` 无需返回）

## 运行验证

```powershell
Get-Content BML\logs\latest.log -Tail 40 | Select-String "example_hello"
```

- [ ] 日志中出现 `[<id>]开始加载` 与 `[<id>]加载完成`
- [ ] 界面中出现登记的页面 / 设置项 / 托盘项
- [ ] 切换语言后，内置控件的文案随之更新（自绘控件除外）
- [ ] 令 `__init__` 抛出异常后：仅该插件失败，启动器正常启动
- [ ] 停用或重载后，该插件的条目、订阅与控件均已移除
