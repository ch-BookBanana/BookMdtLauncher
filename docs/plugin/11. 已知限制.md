# 已知限制

| 限制 | 说明 | 替代做法 |
|------|------|---------|
| 语言热切换没有插件回调 | 自绘控件在创建时读一次文案，运行中切语言不会重取 | 文案尽量用内置控件（`title` 是语言键，会自动重取）；自绘控件在需要时按 `events.lang.get` 重建 |
| 主题切换没有插件回调 | 同上：`events.settings["theme"]` 只在取的那一刻有效 | 样式走 `core/qss`（切主题时宿主会重收一遍） |
| 浮层页面需要宿主入口 | `core/overlays` / `core/stacks` 只负责登记页面，打开动作在宿主侧；左栏页面不受此限 | 需要直接入口时登记 `core/pages` |
| 停用的插件没有界面开关 | 只能用 `pluginLoader.enable(id)`、触发一次重载，或编辑 `settings.json` | — |
| 直接写 `self.settings[k]` 不触发回调 | 只有 `self.set_config(k, v)`（与 `register("settings").set`）会通知 `watch_config` 的监听者 | 需要通知时统一走 `self.set_config` |
| 设置只校验键名、不校验值类型 | 键必须先声明（`settings_defaults` 或 `declare`），未声明写入当场报错；但值允许任意类型 | 在 `__init__` 里自行校验值 |
| 停用 / 重载时已打开的浮层不会自动关闭 | 卸载插件后，由它的 `overlays` / `stacks` 条目打开、当时仍开着的页面会留在叠层里，其上的按钮可能仍引用已卸载的实例 | 重载插件前先关掉该页面 |
| 插件直接塞进宿主页面的控件不归宿主管 | 只有经扩展点登记的条目会被对账；`parent.layout().addWidget(...)` 塞进去的控件没有任何登记 | 通过扩展点登记，或在 `on_close()` 里摘掉 |
| `import` 拿到的对方代码是冻结的 | 拿到的是 import 那一刻的类对象，提供方之后被重载，旧引用仍指向旧代码 | 要跟着提供方生命周期走的东西用 `self.use("<id>.<名字>")` |
| 事件不能当函数调用 | 信号是单向广播，拿它做请求-响应会让调用方挂在永远不返回的 `emit` 上 | 需要返回值就用 `self.use(...)` / 读注册表 |
| `${plugin}/` 只在构造期有效 | 运行期没有「当前插件目录」上下文，`getPath("${plugin}/…")` 会失效 | 构造期取好绝对路径，或随时用 `self.path(...)` |
| `self.download(...)` 只额外开放 `state_dir` | 下载器参数与宿主那一套一致，没有插件专属的其它新参数 | 需要别的行为就自己起线程 + 自带的网络库 |
| 同一个 id 只能装一份 | 重复加载会失败（提示「已经加载着」），不会出现两份实例 | 先卸载再重载 |
| 卸载不删设置与 `pluginData` | 停用再启用时配置还在；彻底清掉要显式删 | `self.settings` 那一格可用 `forget()` 摘掉 |

## 组合写法

```python
from PySide6.QtWidgets import QLabel, QVBoxLayout, QWidget

from BMLCore import BMLPlugin, Widgets, events, registrar


class GreetPanel(QWidget):
    """主题取色在构造时读一次：目前没有主题切换回调。"""

    def __init__(self, parent=None):
        super().__init__()
        light = bool(events.settings["theme"])                 # True 为浅色
        color = "#787878" if light else "#c8c8c8"

        lay = QVBoxLayout(self)
        hint = QLabel("自绘控件")
        hint.setStyleSheet("color: %s;" % color)               # 也可改用 qss 选择 objectName
        lay.addWidget(hint)


class Hello(BMLPlugin):
    id = "example_hello"
    settings_defaults = {"volume": 50, "greet": True}

    # 自绘控件用的样式：两套主题都给一份（theme=True / False），比在代码里判主题稳
    light_css = registrar("core/qss").new("hello.light", qss="QLabel#helloHint { color: #787878; }",
                                          theme=True)
    dark_css = registrar("core/qss").new("hello.dark", qss="QLabel#helloHint { color: #c8c8c8; }",
                                         theme=False)

    # 文案使用内置控件：title 是语言键，切换语言时自动更新
    @registrar("core/setting/items").new(title="hello.greet",
                                         section="core.setting.plugins", order=910)
    def build_greet(self, ctx):
        return Widgets.Bool(ctx.parent, ctx.title)

    @registrar("core/pages").new(title="hello.page", order=50)
    def build_page(self, ctx):
        return GreetPanel(ctx.parent)

    def set_volume(self, value):
        # 写入设置的同时通知自身逻辑：set_config 会驱动 watch_config
        self.set_config("volume", value)
```
