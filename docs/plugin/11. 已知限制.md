# 已知限制

| 限制 | 说明 | 替代做法 |
|------|------|---------|
| 主题与语言热切换未对插件开放回调 | 运行中切换语言不会通知插件自绘控件，自绘控件仅在创建时读取一次文案 | 样式使用 `registrar.qss(theme=…)`（切换主题时重新收集）；文案尽量使用内置控件，其 `title` 为语言键 |
| 浮层页面需要宿主入口 | `@registrar.overlay` / `@registrar.stack` 只登记页面，打开动作在宿主侧；左栏页面不受此限 | 需要直接入口时使用 `@registrar.page` |
| 停用的插件没有界面开关 | 只能编辑 `settings.json` 的 `disabledPlugins` | — |
| 直接写 `self.settings[k]` 不触发回调 | 只有 `self.set_config(k, v)` 会通知 `watch_config` 的监听者 | 需要通知时统一走 `self.set_config` |
| 插件设置没有 schema 校验 | 写入任意键值都会保存；默认值来自 `settings_defaults` | 在 `__init__` 中自行校验 |
| API 仍在定稿 | `API_VERSION` 为 `1.0` | 在清单中声明 `api = "1.x"` |
| 停用 / 重载时已打开的浮层不会自动关闭 | 卸载插件后，由它的 `@registrar.overlay` / `stack` 条目打开、且当时仍开着的页面会留在叠层里；其上的按钮可能仍引用已卸载的实例 | 重载插件前先关掉该页面 |
| 插件运行期自行塞进宿主页面的控件不归宿主管 | 只有经扩展点登记的条目会被对账；直接 `parent.layout().addWidget(...)` 塞进去的控件没有任何登记 | 通过扩展点登记，或在自己的 `on_close()` 里摘掉 |
| 用 import 拿到的对方代码是冻结的 | `from bmlplugin.<id> import X` 拿到的是 import 那一刻的类对象；提供方之后被重载，旧引用仍指向旧代码 | 要跟着提供方生命周期走的东西用 `self.use("<id>.<名字>")` 拿活句柄 |

## 组合写法

```python
from PySide6.QtGui import QColor
from PySide6.QtWidgets import QLabel, QVBoxLayout, QWidget

from BMLCore import BMLPlugin, Widgets, events, registrar


class GreetPanel(QWidget):
    """主题取色在构造时读取一次：目前没有主题切换回调。"""

    def __init__(self, parent=None):
        super().__init__()
        light = bool(events.settings["theme"])                  # True 为浅色
        color = QColor(120, 120, 120) if light else QColor(200, 200, 200)

        lay = QVBoxLayout(self)
        hint = QLabel("自绘控件")
        hint.setStyleSheet("color: %s;" % color.name())         # 亦可改用 qss 选择 objectName
        lay.addWidget(hint)


class Hello(BMLPlugin):
    id = "example_hello"

    # 文案使用内置控件：其 title 为语言键，切换语言时自动更新
    @registrar.setting(title="hello.greet")
    def build_greet(self, ctx):
        return Widgets.Bool(ctx.parent, ctx.title)

    # 写入设置的同时通知自身逻辑
    def set_volume(self, value):
        self.set_config("volume", value)
        self._apply(value)

    def _apply(self, value):
        self.log("音量改为 %s" % value)
```
