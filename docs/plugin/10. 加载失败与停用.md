# 加载失败与停用

正常加载：

```text
[example_hello]开始加载
[example_hello]加载完成
```

加载失败：

```text
[example_hello]加载失败:
<Traceback ...>
[example_hello]已标注停用，下次启动不再加载它
```

失败后的行为：

- 仅影响该插件；其它插件正常加载，启动器正常启动。
- 本次登记的条目整体回滚。
- 插件 id 写入 `settings.json` 的 `disabledPlugins`：

```json
{ "disabledPlugins": ["example_hello"] }
```

## 恢复方式

1. 依据日志中的 traceback 修复插件；
2. 将 id 从 `BML/settings.json` 的 `disabledPlugins` 中移除；
3. 重启启动器。

> 当前版本没有界面入口执行上述操作，只能编辑 `settings.json`。

## 常见原因

| 现象 | 原因 |
|------|------|
| `插件不得 import 'src.utils.events'` | 导入了内部模块；插件只允许 `from BMLCore import …` |
| `要求 API 1.1，当前宿主是 1.0` | 清单中的 `api` 高于宿主版本 |
| `入口文件不存在` | 清单的 `main` 指向的文件不存在或未随插件提供 |
| `里找不到 entry_class = 'X'` | `entry_class` 名称有误，或该类不是 `Plugin` 子类 |
| `依赖加载失败：xxx` | 依赖未安装、被停用或自身加载失败 |
| 加载成功但界面无内容 | 装饰器标注的方法未返回控件 |
