# 事件与托盘

## 事件

提供方：订阅宿主事件，并以自身事件转发：

```python
from BMLCore import BMLPlugin, registrar


class Base(BMLPlugin):
    id = "example_base"

    @registrar.on("start_gameChanged")          # 订阅宿主事件，参数与宿主 emit 一致
    def on_game(self, data):
        self.log("宿主切换游戏：%s" % (data,))
        # emit 自动加上 id 前缀，实际事件名为 example_base.game
        self.emit("game", data)
```

使用方：订阅提供方的事件（清单中需声明依赖）：

```python
class Child(BMLPlugin):
    id = "example_child"                    # manifest.toml 中依赖 example_base

    @registrar.on("example_base.game")      # 订阅其它插件的事件，书写完整事件名
    def on_base_game(self, data):
        self.log("base 切换游戏：%s" % (data,))
```

| 方式 | 说明 |
|------|------|
| `@registrar.on("名称")` | 订阅事件，方法参数与 emit 参数一致 |
| `self.emit("名称", *args)` | 广播自身事件，名称自动加 `<id>.` 前缀 |
| `self.on("名称", 回调)` | 运行时订阅（非方法无法使用装饰器） |

事件为单向广播，用于通知与命令。需要返回值时使用具名接口——将事件当作函数调用会使调用方
阻塞在不会返回的 `emit` 上。卸载时按 `<id>` 前缀摘除订阅。

## 托盘

```python
from BMLCore import BMLPlugin, registrar


class Hello(BMLPlugin):
    id = "example_hello"

    @registrar.tray(title="hello.about", order=10)   # title 为语言键
    def about(self):
        self.log("托盘项被触发")                      # 无参回调

    def __init__(self, host):
        super().__init__(host)

        # 亦可在运行时添加（例如依据设置决定是否添加）
        if self.get_config("show_refresh", True):
            self.add_tray("refresh", title="hello.refresh",
                          callback=self.refresh, order=20)

    def refresh(self):
        self.log("刷新项被触发")
```

- `title` 为语言键，切换语言时托盘会重新设置文案。
- 托盘条目仅承载单项动作；需要打开界面时应登记页面。
- 托盘中原有的「关闭」项不由插件修改。
