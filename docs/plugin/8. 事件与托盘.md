# 事件与托盘

## 信号全部走全局总线

v2 不再有自定义 `Signals` 类，也不再有 Notifier 模式：所有信号都在**全局信号总线**上，
入口是 `register("signals")`（`self.signals` 就是这条总线本身，即 `events`）。

| 写法 | 说明 |
|------|------|
| `register("signals").new("进度")` | 声明自己的信号；名字自动加 `"<id>."` 前缀 |
| `register("signals").set("进度", 0.5)` | 发（自动加前缀） |
| `register("signals").watch("进度", cb)` | 订（自动加前缀；订阅记在自己名下，卸载自动摘） |
| `self.signals.on("example_base.game", cb)` | 直接操作总线：写**完整**名字 |
| `self.emit("game", data)` | 便捷转发：发 `<id>.game` |
| `self.on("example_base.game", cb)` | 便捷转发：**按完整名字**订阅，订阅记在自己名下 |

宿主信号（`core.*` 或 `plugins_changed` / `start_gameChanged` 这类全局名）同样可订：这类名字不是
自己的，用 `self.on("全名", cb)` 或 `self.signals.on("全名", cb)` 写全名字；`register("signals")`
那套会自动加 `"<id>."` 前缀，所以它只适合自己这一侧的信号。

## 提供方

```python
from BMLCore import BMLPlugin, registrar


class Base(BMLPlugin):
    id = "example_base"

    game = registrar("signals").new("game")          # 声明，实际名字是 example_base.game

    def __init__(self, host=None):
        super().__init__(host)
        self.on("start_gameChanged", self._on_host_game)   # 订宿主信号：写全名
        self.register("signals").watch("game", self._on_game)   # 订自己的：自动加前缀

    def _on_host_game(self, data):
        self.log("宿主切换游戏：%s" % (data,))
        self.register("signals").set("game", data)   # 发自己的信号

    def _on_game(self, data):
        self.log("自己的信号到了：%s" % (data,))
```

## 使用方

```python
class Child(BMLPlugin):
    id = "example_child"                # 清单里 dependencies 写 "example_base"

    def __init__(self, host=None):
        super().__init__(host)
        # 别人的信号：写全名（它不会被自动加前缀）
        self.register("signals").watch("example_base.game", self._on_base_game)

    def _on_base_game(self, data):
        self.log("base 切换游戏：%s" % (data,))
```

## 约定

- 订阅一律记在自己名下：卸载 / dispose 时自动摘，包括**订别人的**那些事件；否则回调还会被叫到
  （那会儿控件已销毁），而且每重载一次多挂一份。
- 事件是单向广播，用于通知与命令。**需要返回值的查询别用事件**：广播不是函数调用，调用方会挂在
  一个永远不返回的 `emit` 上。要取东西用 `self.use("example_base.xxx")`，或读注册表。
- 确实需要 Qt 信号时，把 `QObject` 定义留在插件模块内部也没问题；但插件之间的通信统一走总线。

## 托盘

```python
from PySide6.QtGui import QAction

from BMLCore import BMLPlugin, events, registrar


class Hello(BMLPlugin):
    id = "example_hello"

    @registrar("core/tray/menu").new(title="hello.about", order=10)   # title 是语言键
    def about_item(self, ctx):
        act = QAction(events.lang.get("hello.about"), ctx.parent)
        act.triggered.connect(lambda *_: self.log("托盘项被触发"))
        return act                                                   # 返回 QAction

    def on_ready(self):
        # 也可在运行期加（例如依据设置决定加不加）
        if self.get_config("show_refresh", True):
            self.register("core/tray/menu").new("refresh", title="hello.refresh", order=20,
                                                init=self._build_refresh)

    def _build_refresh(self, box):
        act = QAction(events.lang.get("hello.refresh"), box.parent)
        act.triggered.connect(lambda *_: self.log("刷新项被触发"))
        return act
```

- 构建方法返回 `QAction`；`title` 是语言键，切换语言时托盘照它重设文案。
- 托盘条目只承载单项动作；需要打开界面时登记页面。
- 托盘里原有的「关闭」项不由插件修改。
