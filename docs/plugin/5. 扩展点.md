# 扩展点

v2 的登记只有一个出口：`registrar("命名空间")`（`register("命名空间")` 是同一个工厂）。

```python
from BMLCore import BMLPlugin, registrar, register
```

## 命名空间

命名空间写成 `<owner>/<名字>`；**owner 段可省**，省略时就是当前插件。

| 命名空间 | 内容 |
|----------|------|
| `core/pages` | 主窗口左栏导航页 |
| `core/overlays` | 叠加层页面：盖在窗口上、带遮罩、内容居中 |
| `core/stacks` | 整页浮层栈：一页压一页、可逐级返回 |
| `core/setting/pages` | 设置页左栏的子页 |
| `core/setting/sections` | 设置子页里的分组容器 |
| `core/setting/items` | 设置子页里的条目（Bool / Combo / 自绘控件…） |
| `core/gameManager/pages` | 游戏管理浮层左栏的功能页 |
| `core/gameSettings/sections` | 游戏管理页的区块（文件夹 / Java …） |
| `core/download/item/actions` | 下载列表项右侧的操作按钮 |
| `core/download/sources` | 下载页顶部页签的游戏来源 |
| `core/download/tabs` | 下载页左栏的页签 |
| `core/tray/menu` | 系统托盘右键菜单里的一项 |
| `core/qss` | 追加到全局样式表末尾的 css 片段 |
| `core/start/bottom` | 启动页左栏底部的按钮页 |
| `settings` | 当前插件的设置桶 |
| `core/settings` | 宿主设置桶（跨桶读的显式路径） |
| `signals` | 全局信号总线 |
| `<id>/parts` | 自己声明的扩展点（把零件开放给别人） |

## 九个动词

每个命名空间都认同一套动词；在 `settings` / `signals` 上语义略有不同：

| 动词 | 普通扩展点 | `settings` | `signals` |
|------|-----------|-----------|-----------|
| `new` | 登记一项 | 声明键（带默认值） | 声明信号 |
| `set` | 顶掉已有条目（记在自己名下） | 写值 | 发信号 |
| `update` | 改自己那条的字段 | 写值 | 不支持 |
| `remove` | 摘掉自己的一条 | 删键 | 不支持 |
| `get` | 读一条条目 | 读值 | 取信号的持有者 |
| `list` | 列条目 key | 列键 | 列自己的信号名 |
| `owned` | 我名下登记的一切 | 排好序的键 | 自己的信号名 |
| `contract` | 声明 / 查看接口契约 | 默认值表 | 命名空间与前缀 |
| `watch` | 盯注册表变更 | 盯设置键（= `watch_config`） | 订阅事件 |

## 三种写法

### ① 方法上（装饰器）

先记标记，加载器 `apply` 时真正落地。方法收到 `Ctx`，返回值就是控件。

```python
class Hello(BMLPlugin):
    id = "example_hello"

    @registrar("core/pages").new(title="hello.page", order=50)
    def page(self, ctx):
        return MyPage(ctx.parent)                   # 返回 QWidget

    @registrar("core/setting/items").new(title="hello.greet",
                                         section="core.setting.plugins", order=910)
    def build_greet(self, ctx):
        return Widgets.Bool(ctx.parent, ctx.title)

    @registrar("core/tray/menu").new(title="hello.about", order=100)
    def about_item(self, ctx):
        return QAction(self.lang.get("hello.about"), ctx.parent)   # 返回 QAction
```

### ② 类属性（不带函数的标记对象）

```python
class Hello(BMLPlugin):
    id = "example_hello"

    css = registrar("core/qss").new("hello.css", qss="QLabel#x{color:red}", theme=None)
    hello = registrar("signals#hello").new()        # 声明自己的信号
```

### ③ 运行期 `self.register(...)`

只在方法里用；调用当场执行。

```python
def on_ready(self):
    self.register("settings").new("volume", 50)         # 声明
    self.register("settings").set("volume", 30)         # 写
    self.register("settings").get("volume")             # 读
    self.register("settings").watch("volume", self._on_volume)

    self.register("core/settings").get("theme")         # 跨桶读（显式路径）
    self.register("signals#progress").new()            # 声明
    self.register("signals#progress").emit(0.5)       # 发，自动加 "<id>." 前缀
    self.register("signals#progress").connect(self._on_progress)
```

## 各扩展点字段

`init` 是构建函数（装饰器写法里由 DSL 从方法自动包装），其余是登记字段；
`title` 一律是**语言键**，`order` 数值小在前、相同则按 key 排序。

| 扩展点 | 必填 | 可选 | 构建函数返回 |
|--------|------|------|-------------|
| `core/pages` | `init` `title` | `icon` `order` `default` | `QWidget` |
| `core/overlays` | `init` `title` | `order` | `QWidget` |
| `core/stacks` | `init` `title` | `order` | `QWidget` |
| `core/setting/pages` | `init` `title` `icon` | `order` | `QWidget` |
| `core/setting/sections` | `init` `title` | `order` | 分组容器（`Widgets.Section`） |
| `core/setting/items` | `init` `section` `title` | `order` | `QWidget` |
| `core/gameManager/pages` | `init` `title` | `icon` `order` | `QWidget` |
| `core/gameSettings/sections` | `init` | `order` `spacing` | 区块容器 |
| `core/download/item/actions` | `init` `title` `icon` | `order` | 按钮控件 |
| `core/download/sources` | `init` `title` `icon` | `order` | 来源页签 |
| `core/download/tabs` | `init` `title` `icon` | `order` | 页签 |
| `core/tray/menu` | `init` `title` | `order` | `QAction` |
| `core/qss` | `qss` | `theme` `order` | —（片段，不是控件） |
| `core/start/bottom` | `init` | `order` | 按钮页 |

- `section` 指向所属分组条目的 key（如 `"core.setting.plugins"`，即内置那个「插件」分组）。
- `core/pages` 的 `default=True` 那条是启动默认页（没有就取第一页）；它是普通字段，直接写进 `new(...)` 即可。

## 构建函数的约定

- **每次被调用都要返回一个新控件**：宿主会重建条目（页面在提供者变化时重建、设置分组在插件
  集合变化时重建）。返回缓存控件会踩两件事 —— 控件只能有一个父级，第二次构建会把它从原处
  搬走；而重建时旧控件已被销毁，拿回来的是个死对象。
- `init` 收到的 `Ctx` 只有四个字段：`parent`（挂载点，当 Qt parent 用）、`title`（登记时的语言键）、
  `items`（仅分组类条目：这一组容纳的条目）、`entry`（注册表条目）。
- 要登记的不是控件而是服务 / 工厂 / 数据，用 `self.publish(name, obj)`（见[资源与依赖](<9. 资源与依赖.md>)）。

## 覆盖内置条目

要替换宿主或别的插件已有的条目（例如关闭询问 `core/closeAsk`），用 `self.override`：

```python
class Hello(BMLPlugin):
    id = "example_hello"

    def __init__(self, host=None):
        super().__init__(host)
        self.override("core/overlays", "core/closeAsk",
                      init=lambda b: MyCloseAsk(b.parent),
                      order=30, title="hello.closeAsk")
```

- key 是别人那条（`core/closeAsk`），但注册表把它记在你名下；
- 被顶掉的那条不会丢：卸载（或加载失败回滚）时自动还回原位，界面回到上一个提供者的控件；
- 同一插件重复覆盖同一个 key 只更新自己那一层，不会层层堆积。

## 样式片段

```python
class Hello(BMLPlugin):
    id = "example_hello"

    common = registrar("core/qss").new("hello.css", qss="QLabel#helloHead { font-weight: bold; }")
    light = registrar("core/qss").new("hello.light", qss="QLabel#helloHead { color: #223344; }",
                                      theme=True)
    dark = registrar("core/qss").new("hello.dark", qss="QLabel#helloHead { color: #dde3ee; }",
                                     theme=False)
```

| `theme` | 含义 |
|---------|------|
| `None` | 两套主题都加（默认） |
| `True` | 只在浅色 |
| `False` | 只在深色 |

片段排在主题文件之后，同名选择器以它为准；换主题时宿主重新收一遍，插件不用自己监听。

## 自己的扩展点

把零件开放给别人时，先声明契约再登记：

```python
def on_ready(self):
    self.register("example_hello/parts").contract(fields=("init", "title"), required=("init",))
    self.register("example_hello/parts").new("status", title="hello.status", init=lambda b: b.parent)
```

别人按 `"example_hello/parts"` 用 `list` / `get` / `watch` 读，或直接用
`self.use("example_hello.<名字>")` 取发布出来的对象。
