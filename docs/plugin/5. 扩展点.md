# 扩展点

向界面添加内容通过 `registrar` 装饰器完成，参数写在方法定义处。

| 装饰器 | 对应扩展点 | 方法返回值 |
|--------|-----------|-----------|
| `@registrar.page(title=…, icon=…, order=…)` | `core.pages` | 控件 |
| `@registrar.overlay(title=…, order=…)` | `core.overlays` | 控件（带遮罩、居中） |
| `@registrar.stack(title=…, order=…)` | `core.stacks` | 控件（整页浮层栈） |
| `@registrar.section(title=…, order=…)` | `core.setting.sections` | 分组容器 |
| `@registrar.setting(title=…, section=…, order=…)` | `core.setting.items` | 控件 |
| `@registrar.game_page(title=…, icon=…, order=…)` | `core.gameManager.pages` | 控件 |
| `@registrar.tray(title=…, order=…)` | `core.tray.menu` | 无 |
| `@registrar.on("事件名")` | 事件总线 | 无 |
| `@registrar.on_ready()` | — | 无 |
| `styles = registrar.qss(css, theme=…)` | `core.qss` | — |

```python
class Hello(BMLPlugin):
    id = "example_hello"

    @registrar.page(title="hello.page", order=50)
    def page(self, ctx):
        return MyPage(ctx.parent)

    @registrar.section(title="hello.group", order=200)
    def group(self, ctx):
        box = Widgets.Section(ctx.parent, ctx.title, ctx.items)
        box.add_wid(Widgets.Line(ctx.parent))            # 追加一行
        return box

    @registrar.setting(title="hello.greet", section="example_hello.group", order=10)
    def greet(self, ctx):
        return Widgets.Bool(ctx.parent, ctx.title)

    @registrar.game_page(title="hello.mods", order=20)
    def mods(self, ctx):
        return ModsPanel(ctx.parent)

    styles = registrar.qss("QLabel#helloTitle { font-weight: bold; }", theme=True)
```

## 各扩展点字段

| 扩展点 | 必填 | 可选 | 说明 |
|--------|------|------|------|
| `core.download.item.actions` | `init` `title` `icon` | `order` | 下载列表项右侧的操作按钮（下载 / 仓库信息 / 链接） |
| `core.download.sources` | `init` `title` `icon` | `order` | 下载页顶部页签的游戏来源 |
| `core.download.tabs` | `init` `title` `icon` | `order` | 下载页左栏的页签 |
| `core.gameManager.pages` | `init` `title` | `icon` `order` | 游戏管理浮层左栏的功能页（设置 / Mods / …）。icon 可省 |
| `core.gameSettings.sections` | `init` | `order` `spacing` | 游戏管理页的区块（文件夹 / Java …） |
| `core.overlays` | `init` `title` | `order` | 叠加层页面：盖在窗口上、带遮罩、内容居中（见 pages/fOverlay/）。整页浮层栈是另一个点：core.stacks。 |
| `core.pages` | `init` `title` | `icon` `order` `default` | 主窗口左栏导航页。`default=True` 的那一条是启动默认页（没有就取第一页）；装饰器不提供 `default`，需要时用 `self.add("core.pages", …, default=True)` 登记 |
| `core.qss` | `qss` | `theme` `order` | 追加到全局样式表末尾的 css 片段。theme: None = 两套主题都加，False = 只在深色，True = 只在浅色。片段排在主题文件之后，同名选择器以它为准 —— 扩展能盖内置样式，不必改主题文件；换主题时会重新收一遍，不用自己监听。 |
| `core.setting.items` | `init` `section` `title` | `order` | 设置子页里的条目（Bool / Combo / 插件自绘的控件…），section 指向它所属的容器 key（core.setting.sections 里的条目） |
| `core.setting.pages` | `init` `title` `icon` | `order` | 设置页左栏的子页 |
| `core.setting.sections` | `init` `title` | `order` | 设置子页里的分组容器（标题 + 它容纳的条目） |
| `core.stacks` | `init` `title` | `order` | 整页浮层栈：一页压一页、可逐级返回（见 pages/fStack/）。 |
| `core.start.bottom` | `init` | `order` | 启动页左栏底部的按钮页（选择游戏 / 挂起…） |
| `core.tray.menu` | `init` `title` | `order` | 系统托盘右键菜单里的一项：init(Box) 返回 QAction。title 是语言键，语言切换时托盘会照它重设文案。 |

`order` 数值越小越靠前，相同 `order` 按 key 排序。界面参数（控件绑定名、项间距等）不属于
扩展点字段，由界面自身维护。

如需直接操作注册表，可使用 `self.add(point, name, **fields)`：条目 key 会自动加上
`<id>.` 前缀，卸载时按前缀整体摘除。

## 构建函数每次都要给新控件

条目的 `init` / 装饰器里的构建方法，**每次被调用都要返回一个新控件**：

```python
def build_greet(self, ctx):
    return Widgets.Bool(ctx.parent, ctx.title)     # 每次现造
```

宿主会重建条目 —— 插件的页面在提供者变化时重建、设置页的分组在插件集合变化时重建。
把控件缓存起来（`return self._cached`）会踩两件事：控件只能有一个父级，第二次构建会把
它从原处搬走；而重建时旧控件已被销毁，拿回来的是个已经死掉的对象。

需要「登记一个现成的东西」时，用下面两条路，而不是缓存的控件：

| 要登记的东西 | 写法 |
|---|---|
| 服务 / 数据 / 工厂对象（不是控件） | `self.publish(name, obj)`（落地为 `<id>.api` 扩展点上的产物） |
| 自己的扩展点上的现成对象 | 先 `declare(built=("obj",))`，再 `registry.provide(point, key, obj)` |
| 已经建好的控件 | **不要**：控件交给宿主构建（上面那条约束），或在 `init` 里返回它之前先 `setParent(ctx.parent)` 并接受它只能出现一次 |

## 覆盖已有条目

要替换宿主内置的一条（例如关闭询问 `core.closeAsk`），用 `self.override`：

```python
class Hello(BMLPlugin):
    id = "example_hello"

    def __init__(self, host):
        super().__init__(host)
        self.override("core.overlays", "core.closeAsk",
                      init=lambda b: MyCloseAsk(b.parent),
                      order=30, title="hello.closeAsk")
```

- key 是宿主那条（`core.*`），但注册表把它记在本插件名下；
- 被顶掉的那条不会丢：卸载（或加载失败回滚）时自动放回原位，界面回到上一个提供者的控件；
- 同一插件重复覆盖同一个 key 只更新自己那一层，不会层层堆积；
- 覆盖的记录只留在注册表里，界面按注册表对账重建 —— 因此能对账的几处（页面、设置页分组、托盘、样式、语言）都会跟着换回来，已经在打开状态的浮层不会自动关闭（见[已知限制](11.%20已知限制.md)）。
