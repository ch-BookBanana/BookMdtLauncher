# 一.插件基础 | 6.信号与事件

## 自己的信号

```python
me = register()
signals = me.add("signals", type="core/point", entry="core/signal")
signals.add("welcome").connect(self._on_welcome)
...
signals.get("welcome").emit("Mindustry 玩家")
```

## 值变化

`BValue` 自带 `value_changed` 信号成员：

```python
@registrar("settings&a&b&sel.value_changed").connect()
def on_sel(value=None):
    ...
```

## 宿主信号

宿主信号登记在 `core/signals` 点（`core/signal` 类型条目），例如：

```python
@registrar("core/signals&on_game_start").connect()
def on_start(*a):
    ...
```

> 宿主信号的具体清单见[主程序扩展点 · 内置信号](../二.主程序扩展点/6.%20内置信号.md)。

## 主题 / 语言变化

不在 events 总线上，而是主题与语言服务自己的信号；用 registrar 的「条目.成员」路径订阅：

```python
@registrar("core/theme.changed").connect()
def on_theme(self, name=None):         # "dark" / "light"（以后可能 "pink"）
    self.update()

@registrar("core/lang.changed").connect()
def on_lang(self, lang=None):          # 语言代码，如 "zh-CN"
    self.retranslate()
```

- 主题名是给“以后可能有自定义配色”留的口子；要布尔值就用 `register("core/theme").light`
- 类体里的方法在 `apply(plugin)` 时才连，绑定的是插件实例；订阅记在当前 owner
  （插件 id）名下，卸载时自动摘；
- 订阅方是控件/窗口时，可以在运行期连**绑定方法**并加 `silent=True`：
  对象已销毁就直接不连，连接后被销毁自动摘掉，断开失败也不抛：

  ```python
  register("core/lang.changed").connect(self.retranslate, silent=True)
  ```

> 📌 用 `BMLCore.Widgets` 里的控件不用自己订阅：宿主在构造时已替它接好
> `lighting` / `langing`。自己写 QWidget 才需要手动连上面两个信号。

## 注意

- 订阅记在 owner 名下，卸载自动摘
- 事件是单向广播；要返回值就查具名对象（`register(...)`），别拿事件当函数调用
