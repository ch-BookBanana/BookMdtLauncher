# 一.插件基础 | 6.信号与事件

## 自己的信号

```python
me = register()
bus = me.add("signals", type="core/point", entry="core/signal")
bus.add("welcome").connect(self._on_welcome)
...
bus.get("welcome").emit("Mindustry 玩家")
```

## 值变化

`BValue` 自带 `value_changed` 信号成员：

```python
@registrar("settings$a$b$sel.value_changed").connect()
def on_sel(value=None):
    ...
```

## 宿主信号

宿主信号登记在 `core/signals` 点（`core/signal` 类型条目），例如：

```python
@registrar("core/signals&on_game_start").connect()
def on_start(*a):
    ...
```

> 宿主信号的具体清单见[主程序扩展点 · 内置信号](../二.主程序扩展点/6.%20内置信号.md)。

## 注意

- 订阅记在 owner 名下，卸载自动摘
- 事件是单向广播；要返回值就查具名对象（`register(...)`），别拿事件当函数调用
