# 一.插件基础 | 4.生命周期

```
发现插件 → 开加载会话(begin) → 导入模块 → 构造 __init__(host)
   ├─ 失败：abort（暂存全丢）→ 报错/停用
   └─ 成功：commit（条目并进正表）
→ 所有插件加载完 → on_ready()（界面还没建）
→ 卸载：unload(owner) 摘自己点上的条目 → on_close() → cleanup() → 删控件
```

## 钩子

- `__init__(self, host)`：登记都写在这里（或模块级用 `@registrar(...)`）
- `on_ready()`：全部加载完、界面构建前
- `on_close()`：卸载时（停线程、存数据）；加载失败回滚时也会被调

## 宿主替你收拾的资源

```python
self.every(1000, self._tick)                 # 周期
self.task(0, self._job)                      # 后台任务（QThTimer）
self.download(url, dest_path)                # 下载（卸载自动取消+等 5s）
self.thread(job)                             # 一次性线程（卸载 join 5s）
```

`self.cleanup()` 由加载器在 `on_close` 之后调：计时器停、下载取消、线程 join。

## 会话期间注意

- 构造里写的登记都是**暂存**，此时不要自己 `unload` 自己
- `register()` 认「当前 owner」：加载期 = 插件，`on_ready` 里 loading 器也套了上下文；宿主启动期 = `core`
