# 一.插件基础 | 8.加载失败与停用

- 失败原因记在 `PluginInfo.error`，界面标红；日志里插件自己那行以 `[id]` 开头
- 失败一次后写入 `settings.json` 的 `disabledPlugins`，下次启动跳过它
- 修好后：`pluginLoader.enable("id")` 或触发一次重载（会连同停用名单重试）
- 清单坏掉（JSON 非法 / 缺必填）在「发现阶段」就失败，不会进入加载

常见原因：

| 现象 | 原因 |
|---|---|
| `入口文件不存在` | `entry` 指向的模块不存在 |
| `找不到 Plugin 子类` | 入口模块没定义本文件里的 Plugin 子类 |
| `要求 API …，当前宿主是 …` | 清单 `api` 与宿主不兼容 |
| `缺必填字段` / `未知字段` | 登记进有契约的点时字段不对 |
| `已经加载着` | 同一个 id 装了两份 |
