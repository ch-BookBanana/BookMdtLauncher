# 一.插件基础 | 2.类型系统

> 📌 一句话：**万物皆 BType**（像 PySide6 里万物皆 QObject）。
> 点、信号、值、日志器、设置……都是登记在 `BTypes` 里的类型实例。

## BTypes：全局类型库

```python
from BMLCore import BTypes, BType

@BTypes.new("myplugin/status")
class Status(BTypes.get("core/type")):
    ...
```

| 方法 | 说明 |
|---|---|
| `BTypes.new(名字)` | 装饰器，登记一个 BType 子类；名字要带命名空间（`myplugin/xxx`） |
| `BTypes.get(名字)` | 取类；不存在抛 `KeyError`（附已登记清单） |
| `BTypes.names()` | 已登记的类型名列表 |

### 登记时的两道检查

1. **成员引用必须已登记**：`init = {"x": "demo/not_exists"}` → 报错并撤回登记
2. **成员不能成环**：`a → b → a`（含自引用）→ `ValueError: 类型成员循环依赖：…`

> ⚠️ 失败的类型不会留在库里，可以修好后重新 `BTypes.new`。

## BType：底座

```python
class BType:
    init = {}          # 成员声明：{成员名: 类型名}
```

- 构造时按 `init` 自动造好成员，放在 **`self.init[成员名]`**
- 类上的 `init` 是声明本身，实例不覆盖它；实例保留备份 `self._init_def`
- 子类可以加字段、方法；`self.member("名字")` 是取成员的便捷写法

```python
@BTypes.new("myplugin/status")
class Status(BTypes.get("core/type")):
    init = {"value": "core/value", "changed": "core/signal"}

s = Status(name="x")
s.init["value"].set(1)            # BValue
s.init["changed"].emit(1)         # BSignal
```

## 内置类型

| 类型 | 类 | 职责 |
|---|---|---|
| `core/type` | BType | 底座 |
| `core/point` | BPoint | 注册点：收条目（add/get/set/remove/watch/覆盖栈/产物槽） |
| `core/signal` | BSignal | 包一层 Qt Signal（emit/connect/disconnect） |
| `core/value` | BValue | 包一个值，带 `value_changed` 信号成员 |
| `core/log` | BLog | 宿主日志（debug/info/warning/error） |
| `core/lang` | BLang | 宿主翻译（get(键)） |
| `core/settings` | BSettings | 宿主设置（get/set/other） |
| `core/setting` | BSettingPoint | 设置组点：**add 底层逻辑被覆写**（见[设置与存储](5.%20设置与存储.md)） |

## BPoint 常用方法

```python
p = register().add("parts", type="core/point", entry="core/value")

p.add("theme")            # 加条目；同 key 反复 add 拿同一个
p.get("theme")            # 取条目（不存在 → KeyError）
p.set("theme")            # 压一层（覆盖栈；顶的人卸载后自动还回）
p.update("theme", ...)    # 改自己那一条的字段
p.remove("theme")
p.keys() / p.entries()    # 键 / 条目实例
p.watch(cb)               # 条目增删改 → cb(key)
p.bind("theme", obj=…)    # 产物槽：挂活对象
p.built("theme")          # 读产物槽
```

> 📌 `add(名字, type="core/point", entry=…)` 建子点；`title` / `icon`
> 等字段直接成为子点属性——界面按点遍历就能拿到「带标题的组」。

## 信号与值

```python
bus = me.add("signals", type="core/point", entry="core/signal")
bus.add("welcome").connect(self._on_welcome)
bus.get("welcome").emit("hi")

v = me.add("vals", type="core/point", entry="core/value")
v.add("theme").set("dark")        # set 会发 value_changed
v.get("theme").value_changed.connect(cb)
```
