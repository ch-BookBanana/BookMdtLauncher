# 一.插件基础 | 7.内置服务

宿主启动时登记到 `core` 点下，插件直接用 `register("名字")` 取（都拿到包装过的 BType，
不是宿主对象本体）：

| 名字 | 类型 | 用法 |
|---|---|---|
| `core/log` | BLog | `register("core/log").info("…")`（debug/info/warning/error） |
| `core/lang` | BLang | `.get("键")` / `@registrar("core/lang.changed").connect()` |
| `core/theme` | BTheme | `.get("brand")` / `.light` / `@registrar("core/theme.changed").connect()` |
| `core/settings` | BSettings | `.get(键)` / `.set(键, 值)` / `.other(owner)` |
| `core/tools` | BPoint | `register("core/tools").get("mdtManager").get()` 拿工具对象 |
| `core/signals` | BPoint | 宿主信号（见[内置信号](../二.主程序扩展点/6.%20内置信号.md)） |

`core/theme` 的角色名：`brand / panel / panel_alt / text / text_dim / line / danger /
warn / ok / icon / icon_strong / scrim`（定义见 `src/utils/palette.py`，明暗两套各取
各的值；`get(名字, light)` 可显式指定，省略则用当前主题）。

### 主题 / 语言变化

两者都带 `changed` 信号；用 registrar 的「条目.成员」路径订阅（卸载自动摘）：

```python
@registrar("core/theme.changed").connect()
def on_theme(self, name=None):     # "dark" / "light"（以后可能 "pink"）
    self.update()

@registrar("core/lang.changed").connect()
def on_lang(self, lang=None):      # 语言代码，如 "zh-CN"
    self.retranslate()
```

取色与取文案仍然走条目方法：

```python
theme = register("core/theme")
theme.get("panel")                  # 当前主题
theme.get("panel", True)            # 显式浅色
theme.light                         # True / False

lang = register("core/lang")
lang.get("hello.title")
```

> 📌 它们**不在 `core/signals` 里**：主题 / 语言是服务上的信号，谁需要谁订阅，
> 不走 events 总线。`core/theme` 的 `set()` 只在宿主侧，插件只能读。
>
> 📌 订阅方是控件/窗口时给 `.connect(silent=True)`（运行期连绑定方法）：对象已
> 销毁就不连、连接后被销毁自动摘掉、断开失败也不抛。

插件自己声明的点：[3. 注册语法](3.%20注册语法.md)。
