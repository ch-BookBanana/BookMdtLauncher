# 一.插件基础 | 7.内置服务

宿主启动时登记到 `core` 点下，插件直接用 `register("名字")` 取（都拿到包装过的 BType，
不是宿主对象本体）：

| 名字 | 类型 | 用法 |
|---|---|---|
| `core/log` | BLog | `register("core/log").info("…")`（debug/info/warning/error） |
| `core/lang` | BLang | `register("core/lang").get("键")` |
| `core/settings` | BSettings | `.get(键)` / `.set(键, 值)` / `.other(owner)` |
| `core/tools` | BPoint | `register("core/tools").get("mdtManager").get()` 拿工具对象 |
| `core/signals` | BPoint | 宿主信号（见[内置信号](../二.主程序扩展点/6.%20内置信号.md)） |

插件自己声明的点：[3. 注册语法](3.%20注册语法.md)。
