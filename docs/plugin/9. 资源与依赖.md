# 资源与依赖

## 插件资源

```python
from PySide6.QtGui import QIcon

from BMLCore import BMLPlugin, getPath, registrar


class Hello(BMLPlugin):
    id = "example_hello"

    def __init__(self, host=None):
        super().__init__(host)

        # self.path(相对插件目录) → 绝对路径；任何阶段都能调
        self.icon_path = self.path("assets/icon.png")
        self.icon = QIcon(self.icon_path)
        self.log("图标位于 %s" % self.icon_path)

        # ${plugin}/ 只在这一刻有效：插件要在构造期把资源路径取好
        legacy = getPath("${plugin}/assets/icon.png")

        # 私有目录：不存在时自动创建，重装插件之后仍然保留
        self.log("私有目录：%s" % self.workspace)

    @registrar("core/pages").new(title="hello.page", order=50)
    def build_page(self, ctx):
        return GreetPanel(ctx.parent)
```

| 取法 | 何时可用 | 说明 |
|------|---------|------|
| `self.path("assets/icon.png")` | 任何阶段 | 推荐；返回插件目录内文件的绝对路径 |
| `getPath("${plugin}/assets/icon.png")` | **仅构造期** | 老写法；运行期没有插件目录上下文 |
| `self.workspace` | 任何阶段 | `BML/pluginData/<id>/`，私有可写目录，不存在时自动建 |

写入私有目录：

```python
import os


def save_note(self, text):
    path = os.path.join(self.workspace, "note.txt")     # 目录不存在时自动创建
    with open(path, "w", encoding="utf-8") as f:
        f.write(text)
```

安装位置不作为依赖：换目录、换打包方式（目录 / `.zip`）都不用改插件代码。

## 依赖

```hjson
// BML/plugins/child/data.hjson
{
  id: example_child
  version: 1.0.0
  api: 2.x
  dependencies: [example_base>=1.2.0,<2.0.0]     // 只依赖一个时也可以写字符串
}
```

| 写法 | 含义 |
|------|------|
| `"example_base"` | 只要装着（不限版本） |
| `"example_base>=1.2.0,<2.0.0"` | 单边多条件 |
| `"1.2.0<=example_base<=1.5.0"` | 两边夹 |

- 加载器按加载顺序先把依赖拉起来，再校验版本：不满足 = **这个插件**整体加载失败，
  依赖链上的其它插件不受影响。
- 依赖没装、被停用、自身加载失败或成环，依赖方这轮也起不来（依赖方的状态不会自动进停用名单，
  装上缺的那个之后下次启动就会跟着起来）。
- 依赖先加载，所以依赖方的 `__init__` 里已经能读到依赖方登记过的条目。

```python
class Child(BMLPlugin):
    id = "example_child"

    def __init__(self, host=None):
        super().__init__(host)
        # 依赖先加载：此刻已能读它登记的条目
        keys = self.register("example_base/parts").list()
        self.log("base 的零件：%s" % keys)
```

## 插件之间取对象：用 `self.use`

推荐方式是把要共享的东西 `publish` 出去，对方用 `self.use(key)` 取**活句柄**。
不要 `import` 对方的模块文件 —— 那样拿到的是导入那一刻冻住的代码，对方重载后这边仍是旧的。

```python
# 提供方
from BMLCore import Plugin


class FancyBool:
    """本插件自己的控件类，供别的插件构造。"""

    def __init__(self, label, color):
        self.label = label
        self.color = color


class Widgets:
    Bool = FancyBool

    @staticmethod
    def divider(width=1):
        return "—" * width


class More(Plugin):
    id = "example_more"

    def __init__(self, host=None):
        super().__init__(host)
        self.publish("widgets", Widgets())      # → example_more.widgets
```

```python
# 使用方：data.hjson 里 dependencies = [example_more]
from BMLCore import Plugin, registrar


class User(Plugin):
    id = "example_user"

    def __init__(self, host=None):
        super().__init__(host)
        self.api = self.use("example_more.widgets")     # 活句柄，存进 self 是安全的

    @registrar("core/pages").new(title="user.page", order=60)
    def build_page(self, ctx):
        return self.api.Bool("标签", "red")             # 取属性时才现查
```

活句柄的几个行为：

| 用法 | 结果 |
|------|------|
| `self.use("example_more.widgets").divider(3)` | 每次取属性都按 key 现查，提供方重载后自然指向新那份 |
| `bool(service)` | 提供方还在就是真 —— 用来判断「它还在不在」 |
| `service.target` | 当前那一份对象本身（要转交给别的接口时用） |
| 提供方被卸载后再用 | 当场抛 `AttributeError`（消息里带着该扩展点现有的条目），不会拿到半死的对象 |
| `key` 不写成 `<提供方 id>.<名字>` | 立刻 `ValueError` |
